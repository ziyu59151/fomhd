# `tools/case_config.py` implementation pseudocode

## A0-PY-CASE-CONFIG-01 - Documented massless case template

```text
render_massless_example():
  use only the existing strict A0 v1 configuration keys
  set species.electron_inertia=0 and keep physical electron mass positive
  use RK4 and the existing time/domain/solver precision contracts
  obtain the exact massless budget key/unit/norm/gate registry from io
  use a positive representative reference scale with each budget unit
  emit every assignment with one English inline comment containing:
    unit, allowed choice/value, and purpose
  state that finite electron inertia requires explicit 1
  state that the fixture is bounded/local and not global Tokamak validation

CLI:
  require --output
  write the rendered UTF-8 configuration to that exact file
  reject an existing output instead of overwriting it
```

The checked-in `cases/massless-example.toml` is generated by this function and
is verified byte-for-byte against it. The helper does not create geometry,
initial state, a source manifest, a run directory, or a physics model.
