# 单 GPU 作业配方

> Status: active; target `jobs/a0.slurm`. This file defines the user-owned launch contract for the built FOMHD binary.  
> 依赖：[app](../app/fomhd.cpp.md)、[CUDA](../src/cuda/backend.cu.md)、[开发约定](../../development.md)。最近同步：2026-11-04。

## A0-JOB-01 — Launch

```text
read explicit binary_path,case_path,new_output_dir,partition,gpu_type,time_limit
require executable binary and regular input; compute/record binary hash
require new_output_dir absent or empty and separate from source/build
submit user's own ordinary Slurm job with 1 GPU and explicit CPU/memory/time limits
job script:
  set -euo pipefail
  use absolute paths passed by caller; no global LD_LIBRARY_PATH/CUDA_HOME edits
  keep compiler/build directory unchanged during run
  invoke srun <frozen-binary> run <case.toml> --output <new-dir>
  Slurm stdout/stderr stored in a launch-log location then linked/copied to run logs
  disable errexit around srun|tee and copy both PIPESTATUS entries immediately
  log exit_code(program if nonzero,otherwise tee),program_exit_code,
    tee_exit_code and finished_utc; return the first nonzero status
  don't label success after nonzero numerical,program,or tee failure
```

短时 CUDA 正确性探针使用本人 debug 分区立即分配策略，资源不可用则 NOT_RUN，不能转到登录 shell 占 GPU。普通 CPU 小测试不申请 GPU。正式运行的时长/资源由算例规模明确给定；不预设高成本全规模扫描。

记录 Slurm 作业 ID、CUDA_VISIBLE_DEVICES 对应逻辑 ordinal 与实际 device UUID；不改变公用驱动、Toolkit、ACL 或 profiler 策略。NCU 不属于当前运行前置。多版本同时计算使用固定二进制及其实际动态库清单，不在运行中的路径重编译覆盖。
